CSP BRUSH MANAGEMENT

Clip Studio Paint’s asset management is TERRIBLE! You can't even mass edit assets it all has to be done individually. I hoped they would have made an update for it already, but I guess I’ll have to stick to doing it manually for now.

Here’s an AMAZING thread on how to do it yourself! It will take a while to set up but I promise it’s worth the effort.

EXTERNAL HARD DRIVE

I use a Seagate Portable External Hard Drive.

I know these things aren’t cheap, but knowing there’s a backup of my work somewhere gives me peace at night. Also always backup your favorite brushes & tools! You can export them into a separate folder. When I was switching to a new PC the Clip Studio Paint cloud backup didn’t save every single asset during the transfer.

WRITING ✏️

I work best thinking in analog first then organizing it digitally. A lot of my ideas come as random scenes that I flesh out later.

BRAINSTORMING

Sometimes I’ll use a voice memo app to record my ideas when I don't have the energy to write it down.

I also really like using graph planning pads to brainstorm scenes? Actually way more than drawing in my sketchbook, but that’s probably because I use them a lot when I thumbnail comic pages.

GOOGLE DOCS

I only really use it to jot down ideas while I’m on the go. I need something that I can access between my phone and computer then transfer later when I have enough material.

SCRIVENER

Used to organize my story’s lore and characters. I really like the folder system it has and that you can change icons for different sections. Even though I only have the basics , it's enough for my needs.

There might be “better” writing programs out there, but some of them have a crazy learning curve I don’t have time to commit to or are subscription only (instead of a one time payment).
